# El Brieff - Sistema de Diseño

## Identidad de Marca
Sistema visual editorial para un podcast de noticias y análisis breve conducido por Arturo Salazar. La identidad prioriza claridad, velocidad, confianza y lectura inmediata.

**Atributos:**
- Editorial
- Preciso
- Actual
- Sobrio
- Confiable
- Ágil

## Paleta de Colores (Estricta)
- **Primary / Background:** `#121C16` (Carbón verdoso profundo)
- **Surface Elevated:** `#1A2420`
- **Border:** `#2A3530`
- **Ink (Text):** `#FFFFFF`
- **Muted Metadata:** `#9AA3A0`
- **Secondary (Navy):** `#566899`
- **Brand Accent (Sage):** `#78A08A` (Uso moderado)
- **Soft Highlight / Links:** `#A0BFE5`
- **Light Surface (Auxiliar):** `#F5F6F7` con Texto `#121C16`

## Tipografía
- **Display / Wordmark:** Montserrat (o Sans Geométrica Extrabold)
  - Wordmark stack: EL / BRI / EFF (3 líneas), tracking 0.06em, Extrabold.
- **Titulares (H1, H2):** Montserrat, Bold/Extrabold, High contrast.
- **Cuerpo (Body):** Source Sans 3 (o Humanist Sans), legible, 16px base.
- **Firma "Brieffy":** Caveat (o Script elegante), solo para marca productora.

## Componentes y Estilo
- **Radios:** 4px (sm), 10px (md), 16px (lg).
- **Módulos:** Limpios, sin saturación de tarjetas.
- **Hero:** Basado en la composición de portada: Wordmark apilado a la izquierda + Retrato del conductor a la derecha.
- **Idioma:** Español (México).
