# Specs

Este grupo **referencia** contratos técnicos; no los sustituye.

Cuando exista un contrato OpenAPI u otro schema versionado, enlazarlo aquí vía `resource:` en un concepto `type: Spec` o como archivo bajo una ruta canónica del repo (p. ej. `/specs/v1/openapi.yaml` en la raíz del proyecto de implementación).

## Estado v1

* Sin OpenAPI requerido para el sitio estático/SSG inicial.
* Si se introduce CMS headless o BFF, agregar concepto Spec y ADR de contrato.
