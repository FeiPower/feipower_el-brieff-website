# Definition

El **media kit** (o press kit) de El Brieff es el paquete de información oficial para periodistas, marcas y partners: propuesta del podcast, conductor, formato, productor (Brieffy), assets de marca y contacto. En este proyecto se entrega como **PDF descargable** desde el sitio ([FR-009](../requirements/fr-009-media-kit-pdf.md)).
